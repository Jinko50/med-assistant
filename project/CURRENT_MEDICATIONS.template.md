# CURRENT MEDICATIONS

> **This file records what is PRESCRIBED. It does not record what was TAKEN.**
> Actual intake belongs in `HEALTH_TIMELINE.md`. The assistant must never treat this list as proof that a dose was swallowed.
>
> Maintained by family. Upload as `CURRENT_MEDICATIONS.md`.
> Everything below the `EXAMPLE` line is fictional and can be deleted.

**Last updated:** YYYY-MM-DD by ______
**Last reconciled against a prescription or a dispensed box:** YYYY-MM-DD by ______

> **Reconciliation is not the same as editing.** "Last updated" means someone typed something here. "Last reconciled" means someone compared this list, line by line, against the actual prescriptions or the actual boxes on the shelf. The assistant quotes the reconciliation date whenever this list matters, and says when it is old.
>
> Reconcile after every appointment, every discharge, and at least every three months.
