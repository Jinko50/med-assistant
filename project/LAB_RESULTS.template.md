# LAB RESULTS

> Maintained by family. Upload as `LAB_RESULTS.md`.
> **Record only values that were actually read.** A value that could not be read is written `нечитаемо / unreadable` — never estimated, never filled in from memory.
> Keep units and reference ranges exactly as printed on the report. Ranges differ between laboratories.
> Everything below the `EXAMPLE` line is fictional and can be deleted.

**Last updated:** YYYY-MM-DD by ______

## How to add a result

One row per test per date. Newest date first within each table. If the report is in Hebrew or English, keep the original test name in brackets — the assistant will match it.

| Date | Test | Value | Unit | Reference range | Flag | Source |
|---|---|---|---|---|---|---|

`Flag`: `↑` high, `↓` low, `—` normal, `?` unreadable.
`Source`: `lab report photo 2026-06-02`, `clinic printout`, `told by doctor`.
